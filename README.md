# major-system-maker
A Mnemonic Major System generator that gives total freedom to the user.

# No more constraints!
- An open dictionary. You can create your own dictionary (or use the one provided, which has around 185,000 words). The format is as follows:
  ```
  word<TAB>/IPA/
  major	/meɪdʒɝ/
  system	/sɪstʌm/
  ```
- You can create your own consonant map (or use the standard one provided)
- Zero dependencies!
- All offline and private!
- A (suboptimal) way to exclude the plural words from the list (for example, searching for 500 would usually yield words such as "laces". This can be confusing if you already have "lace" for the number 50...)
- Runs on literally anything (including your phone!)
- GPL-3.0 license

# The ugly
- No fancy GUI.
